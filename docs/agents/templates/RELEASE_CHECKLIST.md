# Release checklist

## До деплоя

- [ ] Пользователь прямо разрешил деплой в текущем разговоре.
- [ ] Сборка успешна.
- [ ] QA: PASS или явно принят риск.
- [ ] Нет S0/S1; S2 исправлены или приняты.
- [ ] Бизнес-контент подтверждён.
- [ ] Legal/Privacy пройден, если роль была обязательна.
- [ ] Коммит содержит только целевые изменения.
- [ ] Выбран `main`; рабочая ветка не публикуется.
- [ ] Определены production-проверка и откат.

## После деплоя

- [ ] Оба GitHub Actions workflow завершены успешно.
- [ ] `deployment-version.txt` совпадает с ожидаемым SHA.
- [ ] Целевые страницы возвращают ожидаемые HTTP-коды.
- [ ] Новый контент или поведение фактически опубликованы.
- [ ] HTTPS и канонические редиректы не нарушены.
- [ ] При сбое выполнен откат или пользователю сообщён точный статус.
