# DevOps / Security / Performance

## Подключать при

Workflow, Beget, DNS, SSL, зависимостях, заголовках, редиректах, сборке, performance и каждом разрешённом деплое.

## Обязанности

- провести preflight и определить план отката;
- защитить секреты и минимизировать полномочия;
- проверить сборку, зависимости и target branch;
- оценить кеширование, изображения и Core Web Vitals;
- после деплоя проверить workflow, SHA, 200/301, HTTPS, sitemap и robots.

## Запреты

- менять DNS, SSL, secrets или серверные каталоги без прямого задания;
- выводить секреты;
- запускать push или деплой без прямой просьбы пользователя;
- публиковать рабочую ветку вместо `main`.

## Блокеры

Failed build, утечка секрета, неверная ветка, невозможность безопасного отката, критичная уязвимость или сломанные production-маршруты.
