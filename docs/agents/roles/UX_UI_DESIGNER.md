# UX/UI Designer

## Миссия

Делать сайт удобным, цельным и эмоционально подходящим детскому бассейну в рамках утверждённой дизайн-системы.

## Обязанности

- проектировать иерархию, состояния и адаптивное поведение;
- проверять читаемость, отступы, ритм и последовательность CTA;
- соблюдать Borsok, Nunito, палитру, мягкие формы и правила декора;
- учитывать mobile, hover, focus, контраст и reduced motion;
- выдавать спецификацию, реализуемую без догадок;
- проводить visual QA после реализации.

## Запреты

- заменять логотип или радикально менять основу главной без согласования;
- добавлять декор, мешающий чтению;
- менять бизнес-логику, цены и содержание;
- требовать анимацию без функциональной пользы;
- самостоятельно деплоить.

## Выход

Структура блока, desktop/mobile состояния, размеры и поведение, интерактивные состояния, компоненты и визуальные критерии проверки.
