# Выжимка разговора и требований

## Исходная задача

Пользователь попросил изучить актуальный сайт `kashalotik.ru`, взять оттуда реальные данные и изображения и создать новый дизайн сайта детского бассейна. Утверждён приложенный визуальный концепт с фразой «Первые шаги к большим достижениям».

## Основные предпочтения пользователя

- Утверждённый референс является основой всего сайта.
- Нравятся цветовая схема, мягкие формы, волны и детская подача.
- Оригинальный логотип обязательно должен быть сохранён.
- Пользователь предпочитает быстрые итерации: сделать, показать, затем править.
- Без отдельного указания изменения сначала делаются локально.
- На GitHub отправлять только после прямой команды «деплой» или равнозначного разрешения.

## Главная страница

- Шапка и первый экран должны повторять утверждённую стилистику.
- Крупный заголовок: «Первые шаги к большим достижениям».
- Порядок блоков: занятия, абонементы и цены, тренеры, преимущества, остальные разделы.
- Боковые пузыри по краям страницы не нужны.
- Переходы между разделами должны быть более волнистыми.
- В слайдере нужны анимации и корректно расположенные стрелки.

## Типографика

- Borsok выбран для крупных заголовков.
- Nunito выбран для основного текста и меню.
- Тексты описаний были увеличены и сделаны немного жирнее.
- Заголовок слайдера был немного уменьшен, а описание бассейна увеличено.
- Меню увеличено и визуально выровнено между логотипом и правым блоком.

## Абонементы

- Карточки должны реагировать на наведение и показывать кнопку записи.
- Пробное занятие выделено светло-голубым фоном и свечением.
- Высота карточек при наведении не меняется.
- Цифры количества занятий увеличены примерно в полтора раза.
- Заголовки карточек — прописными буквами.
- Цены — жирные.
- Всё содержимое центрировано.
- Вертикальные расстояния между количеством занятий, ценой и длительностью выровнены.

## Внутренние страницы

- Созданы занятия, расписание, команда, водоподготовка, правила и контакты.
- Меню должно быть полностью одинаковым с главной.
- Отзывы убраны из меню и как отдельная страница.
- Волна под верхним блоком должна отображаться одинаково.
- Китёнок должен находиться внутри контейнера, а не у внешнего края экрана.
- Кит смотрит влево, плавает при наведении и выпускает пузырьки.
- Рядом появляется облачко с одной из десяти случайных фраз о преимуществах бассейна.

## Слайдер и фотографии

- Фотографии второго и третьего слайдов были улучшены с сохранением реальных помещений.
- Они должны быть вписаны в весёлую асимметричную форму, похожую на первый слайд.
- Декоративные элементы должны выглядеть как настоящие каплевидные всплески, а не овалы.
- Добавлены голубая и розовая SVG-брызги и прозрачные пузырьки.
- Кит на этих фотографиях не нужен.

## GitHub и публикация

- Репозиторий: `soulparadise/kashalotik`.
- Публичная ссылка: `https://soulparadise.github.io/kashalotik/`.
- После одного из деплоев пользователь не увидел изменений.
- Проверка показала, что деплой из `main` был отменён запуском из рабочей ветки.
- Workflow исправлен и теперь работает только из `main`.
- После исправления новые изображения и SVG-файлы были проверены по публичным адресам и возвращали HTTP 200.

## Текущее указание о памяти

Пользователь попросил зафиксировать проектные знания и разговор в локальных документах. Эти документы можно сохранить локальным Git-коммитом, но нельзя отправлять на GitHub без нового прямого разрешения.
