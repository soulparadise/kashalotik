# Кашалотик MVP

Локальный статический MVP по утверждённому дизайн-референсу. Данные и изображения взяты с действующего сайта `kashalotik.ru`, оригинальный логотип сохранён в `assets/images/logo.svg`.

## Локальный запуск

```powershell
python -m http.server 8080
```

Откройте `http://127.0.0.1:8080/`.

Сайт не требует сборки и не развёрнут публично.
