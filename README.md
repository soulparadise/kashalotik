# Кашалотик

Статический многостраничный сайт детского бассейна. Все изображения лежат локально в `assets/images`, оригинальный логотип используется из `logo.svg` без изменений.

## Запуск

Откройте `index.html` напрямую либо запустите любой статический сервер из корня проекта, например:

```powershell
python -m http.server 8080
```

После этого сайт доступен по адресу `http://localhost:8080`.

## Страницы

- `index.html` — главная
- `programs.html` — программы
- `prices.html` — цены
- `trainers.html` — команда
- `safety.html` — водоподготовка
- `rules.html` — правила и список вещей
- `contacts.html` — контакты и вопросы

Сайт не требует сборки и подходит для загрузки на обычный статический хостинг.
